# FOODPULSE
Food Delivery Intelligence Platform
  
**An Interactive Business Analytics Platform for Food Delivery Operations**
## Overview
FoodPulse is an end-to-end Food Delivery Intelligence Platform developed to analyze business performance, customer behavior, restaurant operations, and revenue trends.
The platform transforms raw food delivery data into meaningful business insights through SQL-based analysis, Python, and an interactive React dashboard.
It aims to support data-driven decision-making by presenting key business metrics and analytical insights in a centralized dashboard.

## Installation & Setup

**Step 1: Clone the repository**
git clone https://github.com/Sathana0511/Food-Delivery-Intelligence-Platform.git

**Step 2: Navigate to the dashboard directory**
cd Food-Delivery-Intelligence-Platform/foodpulse-dashboard

**Step 3: Install dependencies**
npm install

**Step 4: Start the development server**
npm run dev

Open the local URL displayed in the terminal to access FoodPulse.
